DOCKER: TURN OFF AND ON (run these inside the trustbazaar folder)
---------------------------------------------------------------------------------------------
Turn OFF tonight (keeps all the data):
    docker compose stop
    Then you may quit Docker Desktop (whale icon in the menu bar > Quit Docker Desktop).

Turn ON tomorrow:
    open -a Docker
    docker info --format '{{.ServerVersion}}'    (repeat until it prints a version number)
    docker compose start
    docker compose ps                              (wait until backend and web show "healthy")
    Then open http://localhost:8080

If "docker compose start" says there is nothing to start, use:
    docker compose up -d

Check that it is working:
    docker compose ps
    docker compose logs -f backend                 (live log; press Ctrl+C to leave it)


DO NOT RUN BEFORE THE DEMO
---------------------------------------------------------------------------------------------
    docker compose down -v        erases ALL data (accounts, listings, bids, chat)

If the data ever gets erased, rebuild it in two commands:
    docker compose up --build -d
    docker compose exec -T backend node - < demo-seed.js
